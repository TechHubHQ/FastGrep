# FastGrep CLI

CLI tool to work on both windows and linux for fast grep in large files or across folders as well for a given pattern

## CLI

- search in single file

```bash
fast-grep pattern <file_to_search>
```

- search across given multiple files in current directory

```bash
fast-grep pattern <file1 file2 file3>
```

- search across all files in current directory

```bash
fast-grep pattern <*>
```
